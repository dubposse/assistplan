# AssistPlan

AssistPlan ist eine Webanwendung zur einfachen Einsatz- und Dienstplanung. Sie unterstützt bei der Planung von Mitarbeitenden, Schichten und Einsätzen und verbindet eine regelbasierte automatische Verteilung mit manueller Feinplanung.

## Funktionen

* Verwaltung von Mitarbeitenden und individuellen Planungsvorgaben
* Auswahl unterschiedlicher Schichtmodelle
* Berücksichtigung von Wunschfrei- und Wunsch-Arbeitstagen
* Regelbasierte automatische Verteilung
* Manuelle Anpassung und Feinplanung per Drag & Drop
* Unterstützung bei der Zuordnung von Touren und Einsätzen
* Übersichtliche Darstellung des erstellten Plans

Die automatische Verteilung unterstützt die Planung anhand definierter Regeln. Die abschließende Kontrolle und Anpassung des Dienstplans bleibt beim Anwender.

## Technische Umsetzung

AssistPlan ist in der aktuellen Version als clientseitige Webanwendung umgesetzt.

**Technologien:**

* HTML
* CSS
* JavaScript
* Browserbasierte Verarbeitung ohne Backend und Datenbank

Die Planungslogik wird vollständig im Browser ausgeführt.

## Live-Version

Die aktuelle Version ist unter **assistplan.de** verfügbar.

## Hintergrund

AssistPlan entstand als eigenständiges Entwicklungsprojekt mit dem Ziel, organisatorische Abläufe bei der Einsatz- und Dienstplanung digital abzubilden und unterschiedliche Planungs-, Berechnungs- und Zeitlogiken praktisch umzusetzen.
