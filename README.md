# AssistPlan

**Web-App für einfache Einsatz- und Dienstplanung mit automatisierter Verteilung und manueller Anpassung.**

🌐 https://assistplan.de

## Über AssistPlan

AssistPlan unterstützt kleine Teams bei der Erstellung von Einsatz- und Dienstplänen.

Mitarbeiter, Schichten, planungsfreie Tage und individuelle Wünsche können erfasst und bei der automatischen Vorplanung berücksichtigt werden. 
Der erzeugte Einsatzplan lässt sich anschließend per Drag & Drop manuell anpassen.

Die Anwendung läuft vollständig im Browser und benötigt keine Registrierung oder Installation.

## Funktionen

- Planung für bis zu 10 Mitarbeiter pro Planung
- Ein-, Zwei- und Drei-Schicht-Systeme
- Individuelle Schichtmöglichkeiten je Mitarbeiter
- Wunschfreie Tage und gewünschte Arbeitstage
- Regelbasierte automatische Verteilung
- Manuelle Anpassung per Drag & Drop
- Druckausgabe des fertigen Einsatzplans
- Keine Registrierung erforderlich
- Keine dauerhafte Speicherung der Planungsdaten

## Technische Umsetzung

AssistPlan ist aktuell eine vollständig clientseitige Web-Anwendung.

- HTML
- CSS
- Vanilla JavaScript
- Keine Datenbank
- Kein Backend
- Keine Benutzerkonten
- Verarbeitung der Planungsdaten lokal im Browser

Die automatische Vorplanung basiert auf definierten Regeln und Bedingungen. Die endgültige Entscheidung über den Einsatzplan bleibt beim Anwender.

## Browser-Unterstützung

Die aktuelle Version unterstützt Google Chrome und Microsoft Edge auf Desktop-Geräten.

Smartphones und Tablets werden derzeit nicht unterstützt.
